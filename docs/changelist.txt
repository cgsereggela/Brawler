issues to fix:
- performance: batch and cache the HUD. HudUI redraws every frame and costs about 500 draw calls and ~15 ms (hiding it dropped 1330 -> 830 calls): each chip's round rects, outline polyline, antialiased pip and battle-dot circles, and text are interleaved, so nothing batches. Draw all shapes first via TriBatch (non-antialiased circles; MSAA smooths them), then all text, and only redraw when the scores, names, hover or banner change
- performance: batch the backdrop's additive motes layer and window lights. The motes layer alone is ~250 draw calls and ~6 ms (circles, arcs and rects drawn one by one with antialiasing), and DrawWindows adds a round rect per lit window, which is why the city themes (Mainframe 48 ms, Neon Night 39 ms) are the slowest. Use TriBatch for both, or bake the windows into the land texture and only animate their alpha
- performance: bake static map decorations into the ground texture. MapNode's solids layer only redraws on change, but Godot still replays every cached command each frame (~140 draw calls for shadows and decos). Painting them into the ground image once costs one textured rect
- performance: avoid antialiased=true on DrawCircle, DrawArc and DrawPolyline in per-frame drawing. Each one adds a feathered edge mesh and its own draw call, and 2D MSAA (on in project settings) already smooths edges; measured that MSAA and HDR 2D themselves cost nothing noticeable here
- performance: add a --perfstats flag that prints draw calls, primitives, frame/process/physics ms each second (Performance monitors), plus a per-layer split mode that hides one layer at a time, so these numbers can be re-measured after each fix. Target: under 300 draw calls and 16.6 ms in --themebench, on D3D12 as well as Vulkan
- performance: with vsync on (the default) on this 59 Hz screen, frames that miss 16.9 ms judder between 59 and 30 fps. Once the fixes above land this mostly goes away; an adaptive vsync option (DisplayServer.VSyncMode.Adaptive) in the display settings would soften it on slower machines. Not measured separately
